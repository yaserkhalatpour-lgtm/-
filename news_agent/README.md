# پایشگر اخبار آموزش‌وپرورش

این نسخه RSSها را می‌خواند، خبرهای مرتبط را با کلیدواژه امتیازدهی می‌کند، موارد تکراری را در SQLite نگه می‌دارد و در صورت فعال بودن، خبر را همراه لینک و نام منبع به تلگرام می‌فرستد.

## منبع اولیه
فید عمومی ایرنا در `sources.json` اضافه شده است: `https://www.irna.ir/rss`. این فید عمومی است و همه موضوعات ایرنا را شامل می‌شود؛ فیلتر کلیدواژه‌ای Agent خبرهای مرتبط با آموزش‌وپرورش را جدا می‌کند. منابع تخصصی‌تر را پس از بررسی نشانی RSS می‌توان اضافه کرد.

## تنظیمات محرمانه
در GitHub مخزن → Settings → Secrets and variables → Actions:
- Secret با نام `TELEGRAM_BOT_TOKEN`: توکن ربات
- Secret با نام `TELEGRAM_CHAT_ID`: شناسه عددی کانال/گروه مقصد

در بخش Variables:
- `NEWS_PUBLISH_ENABLED=false` برای اجرای آزمایشی؛ فقط پس از بررسی خروجی آن را `true` کنید.

توکن را هرگز در کد، فایل‌های مخزن یا پیام چت قرار ندهید.

## اجرا
از تب Actions گردش‌کار **Education news monitor** را انتخاب و با **Run workflow** دستی اجرا کنید.

**نکته مهم درباره زمان‌بندی:** این پروژه عمداً روی شاخه جداگانه `education-news-telegram-agent` نگه داشته شده است. GitHub فقط Workflow زمان‌بندی‌شده‌ای را اجرا می‌کند که روی شاخه پیش‌فرض مخزن وجود داشته باشد؛ بنابراین در این مرحله اجرای خودکار هر ۳۰ دقیقه فعال نیست. برای حفظ جدایی از سایت اصلی، زمان‌بندی دائمی را در مرحله استقرار روی سرویس مستقل فعال می‌کنیم، یا با اجازه شما Workflow زمان‌بندی‌شده را جداگانه به شاخه اصلی منتقل می‌کنیم.

## اجرای محلی
```bash
pip install -r requirements.txt
python main.py
```

متغیرهای اختیاری: `NEWS_MIN_SCORE` (پیش‌فرض 4)، `NEWS_MAX_PER_RUN` (پیش‌فرض 8)، `NEWS_FEEDS_JSON` (جایگزین محتوای sources.json).

## ایمنی و محدودیت
انتشار به‌صورت پیش‌فرض خاموش است. این نسخه فیلتر واژگانی دارد، نه راستی‌آزمایی مستقل یا خلاصه‌سازی هوش مصنوعی؛ اخبار حساس استخدامی، حقوقی و بخشنامه‌ها باید با منبع رسمی بررسی شوند. پایگاه SQLite با Cache در اجراهای GitHub Actions بازیابی می‌شود، اما Cache تضمین ذخیره‌سازی دائمی نیست.
