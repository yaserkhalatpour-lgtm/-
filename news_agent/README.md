# پایشگر اخبار آموزش‌وپرورش

این نسخه RSSها را می‌خواند، خبرهای مرتبط را با کلیدواژه امتیازدهی می‌کند، موارد تکراری را در SQLite نگه می‌دارد و در صورت فعال بودن، خبر را همراه لینک و نام منبع به تلگرام می‌فرستد.

## پیش‌نیاز راه‌اندازی
1. فایل `sources.json` را با نشانی RSS واقعی و معتبر منابع رسمی/خبرگزاری‌ها جایگزین کنید. نشانی صفحه اصلی سایت RSS نیست.
2. در GitHub مخزن → Settings → Secrets and variables → Actions، دو Secret بسازید:
   - `TELEGRAM_BOT_TOKEN`: توکن ربات
   - `TELEGRAM_CHAT_ID`: شناسه عددی مقصد کانال/گروه
3. در Variables یک متغیر `NEWS_PUBLISH_ENABLED` با مقدار `false` بسازید. پس از تست موفق و بررسی خروجی، آن را به `true` تغییر دهید.
4. از Actions، گردش‌کار Education news monitor را دستی اجرا کنید.

## اجرای محلی
```bash
pip install -r requirements.txt
python main.py
```

متغیرهای اختیاری: `NEWS_MIN_SCORE` (پیش‌فرض 4)، `NEWS_MAX_PER_RUN` (پیش‌فرض 8)، `NEWS_FEEDS_JSON` (جایگزین محتوای sources.json).

## ایمنی و محدودیت
انتشار به‌صورت پیش‌فرض خاموش است. توکن را هرگز در کد، فایل‌های مخزن یا پیام چت قرار ندهید. این نسخه فیلتر واژگانی دارد، نه راستی‌آزمایی مستقل یا خلاصه‌سازی هوش مصنوعی؛ اخبار حساس استخدامی، حقوقی و بخشنامه‌ها باید با منبع رسمی بررسی شوند. پایگاه SQLite باید در اجرای زمان‌بندی‌شده به‌صورت پایدار نگهداری شود؛ کش ساده GitHub Actions برای جلوگیری از تکرار، تضمین کامل پایداری نیست.
